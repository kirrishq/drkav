# Contributing

## Начало работы

Используйте Node.js 20.19+ и pnpm 11:

```bash
pnpm install
pnpm dev:web
# в отдельном терминале, если нужна локальная CMS
pnpm dev:cms
```

Перед передачей изменений выполните:

```bash
pnpm lint
pnpm typecheck
pnpm build:web
pnpm build:cms
```

## Правила изменений

- Работайте в тематической ветке, не в `main`.
- Strapi 5.51.1 в `apps/cms` и локальная SQLite разрешены для разработки. Seed запускайте только вручную командой `pnpm --filter @drkav/cms seed`.
- Держите UI независимым от Strapi и других CMS. Страницы получают CMS-контент только через `ContentRepository` из `@drkav/content-contracts`; не импортируйте Strapi SDK или Strapi-модели напрямую в UI и страницы.
- Подключайте контент по одной безопасной вертикали; массовое переключение страниц на CMS требует отдельной задачи.
- Добавляйте переиспользуемые компоненты по одному в `packages/ui`, документируйте их на внутренней странице `/design-system` и используйте shared design tokens.
- Сохраняйте Server Components по умолчанию; интерактивное поведение изолируйте в небольших Client Components.
- Не используйте реальные данные пациентов и не добавляйте в репозиторий локальные секреты, SQLite, uploads и generated-файлы Strapi.
- Изменения SEO-URL, Public API, production, hosting, DNS, amoCRM, аналитики и других реальных интеграций требуют отдельного согласования.
- Не выполняйте commit, push или merge без явного разрешения владельца проекта.
- Не используйте CSS Modules. Уникальный класс с префиксом страницы допустим только для специфичного элемента или поведения. Контейнеры, заголовки, сетки, карточки, списки и действия переиспользуют shared-классы и модификаторы из `packages/ui`; не создавайте классы наподобие `contribution-patent-title` для общего заголовка.
