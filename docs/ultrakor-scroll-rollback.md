# Варианты прокрутки модели Ультракора

9 ноября 2026 перед переходом на непрерывную привязку модели к прокрутке сохранён вариант с переключением экранов.

- Локальная Git-метка: `ultrakor-slides-2026-11-09`.
- Коммит: `8e37fd1` (`chore: checkpoint Ultrakor slides before continuous scroll`).
- Содержит оригинальную модель для десктопа, мобильную копию на 100 тысяч треугольников и очищенные от шипов стопы.
- Метка и коммит сохранены в Git и отправлены в origin по запросу владельца проекта.

Чтобы попросить возврат, достаточно написать: «Верни переключение экранов модели из ultrakor-slides-2026-11-09».

Для точечного отката текущей реализации сначала сохраните более поздние изменения этих файлов, затем восстановите их из метки:

```sh
git restore --source=ultrakor-slides-2026-11-09 -- apps/web/src/components/ultrakor-model-section.tsx apps/web/src/components/ultrakor-zone-overlay.tsx apps/web/src/styles/ultrakor.css
```

Это заменяет содержимое трёх файлов версией из метки. Если позже в них появятся другие доработки, следует отменить только изменения непрерывной прокрутки по сравнению с меткой, сохранив остальные правки. Полный сброс репозитория не нужен.

Непрерывный вариант использует прежние восемь ракурсов как ключевые положения. Между ними интерполируются положение, поворот и масштаб модели, камера и её цель. Прокрутка браузера остаётся обычной; сглаживание зависит от времени кадра, а Canvas работает по запросу и перестаёт запрашивать кадры после достижения нужного положения. При включённом системном уменьшении движения дополнительное запаздывание отключено.

После проверки на мобильных восстановлен поэтапный режим при ширине до 700 px: один жест переключает один этап с прежним плавным переходом и остановкой рендера. На десктопе остаётся непрерывная привязка к прокрутке. Облегчённая мобильная модель, дизайн и ракурсы сохранены.
