- [x] Зафиксировать технические и эксплуатационные границы.

## 2. Дизайн-система и интерфейс

- [x] Создать минимальные shared design tokens и внутреннюю страницу документации.
- [x] Реализовать доступный `Button` как первый контролируемый компонент.
- [x] Реализовать `Input`, `Label` и базовую композицию `FormField`.
- [x] Добавить `PhoneInput` с маской, `Checkbox`, `Radio` и `RadioButton`.
- [ ] Утвердить визуальное направление.
- [ ] Добавлять следующие компоненты по одному в отдельных задачах.
- [ ] Вернуться к Storybook после стабилизации финальных компонентов.
- [ ] Реализовать основные страницы на статическом контрактном контенте.

## 3. Контент и запуск

- [x] Выбрать Strapi 5.51.1 для локальной разработки и добавить `apps/cms` с локальной SQLite.
- [x] Подготовить CMS-neutral модели, `ContentRepository` и изолированный Strapi-адаптер без подключения страниц.
- [ ] Подключить одну безопасную контентную вертикаль через `ContentRepository` и проверить fallback и публикационный процесс.
- [ ] Продолжать миграцию постепенно; не переключать страницы на CMS массово.
- [ ] Проверить контент, доступность, производительность и SEO.
- [ ] Отдельно согласовать Public API, production, hosting, DNS, amoCRM, аналитику, другие реальные интеграции и публикацию.
